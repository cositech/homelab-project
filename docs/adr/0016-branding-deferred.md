# ADR 0016 — Product branding remains a codename in Phase 0

**Status:** Accepted

## Decision

`InfraHub Mobile` is a working codename only. Package IDs, App Store identifiers,
logos and public brand are changed only after naming/legal/domain checks.

## Consequences

- implementation must follow this decision unless superseded by a later ADR;
- deviations require an explicit ADR or documented compatibility exception.

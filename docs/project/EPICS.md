# Delivery epics

1. **Secure storage and TLS** — migrate secrets, define trust policy, redact diagnostics.
2. **Capability core** — provider registry, normalized contracts, schema compatibility.
3. **Reference providers** — Proxmox VE and Uptime Kuma migrations.
4. **COStech operations providers** — NetBox, Zammad, PegaProx, Prometheus/Grafana, OneUptime, OPNsense.
5. **Controlled actions** — policy, confirmation, audit, idempotency and recovery.
6. **MSP correlation** — tenants, customers, sites and canonical assets.
7. **Optional integration gateway** — Authentik/OIDC, push, webhooks, MCP/AIOC.
8. **Release engineering** — SBOM, signing, provenance, migration and operational runbooks.

Each epic must ship vertically on Android and iOS or explicitly document a temporary platform gap.

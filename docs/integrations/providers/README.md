# Provider specifications

These files define the initial P0 provider set. They are implementation contracts, not credential setup tutorials. Each implementation must add platform fixtures, authentication/TLS tests, error mapping, redaction tests and a compatibility matrix before it is considered production-ready.

Implemented Phase-2 verticals include Proxmox VE, Uptime Kuma, [Proxmox Backup Server](proxmox-backup-server.md), [Prometheus](prometheus.md) and [Grafana](grafana.md).
